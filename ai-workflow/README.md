# AI Workflow System

A visual AI workflow builder where each node represents a YES/NO decision step.
Built with Next.js, React Flow, and Inngest.

## Setup

1. Clone the repo
2. Copy `.env.example` to `.env.local` and fill in your API keys
3. Run `npm install`
4. Run `npm run dev` in one terminal
5. Run `npx inngest-cli@latest dev` in a second terminal

## Stack
- Next.js (frontend + API routes)
- React Flow (visual canvas)
- Inngest (workflow execution)
- OpenAI (YES/NO decision logic)
